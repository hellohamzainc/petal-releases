# Tenotes releases

Installers for Tenotes, a notes app with tabs, search and end-to-end encrypted sync.

- **Android:** download [`Tenotes.apk`](https://github.com/hellohamzainc/tenotes-releases/releases/latest/download/Tenotes.apk) on your phone and open it. Android asks once to allow installs from your browser or Files app: allow it, then tap Install. New versions install over the old one and keep your notes.
- **Mac (Apple silicon):** download [`Tenotes-mac.dmg`](https://github.com/hellohamzainc/tenotes-releases/releases/latest/download/Tenotes-mac.dmg), open it and drag Tenotes into Applications. The app isn't notarized by Apple yet, so the first time macOS refuses to open it: go to System Settings → Privacy & Security, choose "Open Anyway", and confirm.

Both links always point to the latest release. This repository holds installers only.
